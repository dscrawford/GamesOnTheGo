# Diagrams

D2 sources, laid out with ELK (`d2 --layout elk <name>.d2 <name>.svg`). The
`.d2` is the artifact; the SVGs are committed build output.

| Diagram | Question it answers |
|---|---|
| [system](system.svg) | What runs where, and who talks to whom |
| [ui-design](ui-design.svg) | Which UI modules need a display, and what a pick does |
| [code-design](code-design.svg) | How a file on disk becomes a launched game |
